# Store graphics (generated)

| File                           | Play Console field | Size / format                |
| ------------------------------ | ------------------ | ---------------------------- |
| `icon-512.png`                 | App icon           | 512 × 512, 32-bit PNG        |
| `feature-graphic-1024x500.png` | Feature graphic    | 1024 × 500, 24-bit PNG (RGB) |

Do not edit these by hand: change `assets/brand/mascot-rhino.svg` or `tools/store-graphics.ts`,
then run `npm run store:graphics` (it also refreshes the launcher icons) and commit the result.
Framed screenshots are not committed; get them from the **Store assets** workflow artifact
(`play-store-assets`). See `docs/store/graphics-spec.md` → "How to generate".
